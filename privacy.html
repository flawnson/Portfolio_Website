Privacy Policy

Last updated: June 21, 2026

This website, flawnson.com (the “Site”), is the personal portfolio of Flawnson Tong (“I”, “me”). This policy explains what data the Site accesses, why, and how it is handled. It applies specifically to the Site’s integration with Google APIs and to general visitors of the Site.

Who this applies to

The Google Health / Fitbit integration described below accesses only my own personal health and fitness data, with my own consent, to display a small activity summary on my homepage. The Site does not onboard other users into this integration and does not request, access, or store any other person’s Google account data.

What data is accessed

With my explicit authorization via Google’s OAuth consent screen, the Site reads a limited, read-only set of my own fitness metrics from the Google Health API (sourced from my Fitbit device), which may include:

  • Daily steps and distance
  • Active energy burned and active zone minutes
  • Heart rate and resting heart rate
  • Sleep duration
  • Exercise / workout sessions

Access is strictly read-only. The Site never writes, modifies, or deletes any data in my Google or Fitbit account.

How the data is used

The data is used for a single purpose: to render an aggregated, recent activity summary (for example, steps over the past several days) on the homepage of the Site. It is not used for advertising, profiling, or any automated decision-making, and it is not used to train any machine-learning or AI models.

How the data is stored and shared

  • OAuth tokens and a short-lived cache of recent metrics are stored on my own server in a private, non-public directory with restricted file permissions.
  • Cached data is held only transiently to reduce API calls and to keep the panel populated between refreshes; it is overwritten on each successful update.
  • The data is not sold, rented, or shared with any third party. It is not transferred to anyone, except as needed to operate the Site’s own server-side functionality.

Google API Services — Limited Use disclosure

The Site’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically, data obtained through Google APIs is used only to provide and improve the user-facing feature described above, is not transferred to third parties except as necessary to provide that feature or as required by law, is not used for advertising, and is not used or transferred for purposes of training generalized AI/ML models.

Data retention and revocation

Because the integration uses only my own account, I can revoke the Site’s access at any time from my Google Account permissions page. Upon revocation, the stored tokens become invalid and cached data is no longer refreshed and is cleared on the next maintenance cycle.

Visitor analytics

The Site may use privacy-respecting, cookieless analytics to count aggregate page views. This does not collect personally identifiable information about visitors and is unrelated to the Google Health integration.
